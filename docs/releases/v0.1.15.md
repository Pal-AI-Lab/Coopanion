# Coopanion v0.1.15

**形象包,Coo 能自己换装、调习惯、临时安静**

## 新功能

- **形象包**:桌宠的形象除了内置的 Coo,现在可以是一个形象包。DeepSeek 大肥鱼改成了第一个形象包,用起来和以前一样。装扮页按形象包自己的说明生成打扮的行,比如大肥鱼的「配色」。以后会通过 Steam 创意工坊分发更多形象。
- **形象包的代码在沙箱里运行**:形象包自带的绘制代码在一个单独的隔离页面里运行,不能联网,也连不到桌宠和 Coo,没法替你说话或改设置。
- **Coo 会自己换装、调习惯**:Coo 可以自己换形象和打扮、换 Coo 的配色和配件、改走动多少和呼噜多久。要改音效、大小、黑白模式、悬停按钮或对你的称呼时,会先在气泡里问你,你同意了才改。不想让它动,在「习惯」页取消勾选「允许 Coo 自己调整」。
- **Coo 会临时安静**:你在忙或者夜深了,Coo 可以临时关掉音效、站着不动,到时间自动恢复,你的设置不会变。这期间你自己改了音效或走动,就按你的来。
- **Coo 知道自己现在的样子**:换了形象或打扮后,Coo 会知道自己现在长什么样。某个形象做不了的表情或动作,Coo 会知道换成了哪个,或者没有做。形象没能显示出来时,桌宠换回 Coo,Coo 也会知道原因。

## 改进

- **设置窗口的配色跟着形象包走**:设置窗口的主题色改为由形象包提供。大肥鱼的八套配色和以前一样,之前选过的不受影响。

- Linux x64:`Coopanion-0.1.15-linux-x64.deb` / `.AppImage`

已经装了 0.1.14 的 Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证,第一次打开的方法见 README。
