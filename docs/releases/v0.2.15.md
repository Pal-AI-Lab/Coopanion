# Coopanion v0.2.15

**大肥鱼的眼睛回到原来的位置**

## 修复

- **大肥鱼的眼睛位置不对**:v0.2.14 换了原版配色的虹膜贴图，远侧那只眼的虹膜被画宽、往眼角挪了几个像素，两只眼看起来没对着同一处。现在两只眼的虹膜形状和位置恢复成 v0.2.13 的样子，只去掉了贴图里的高光;会动的高光照旧(感谢 @AL-spiritphoenix,#504)。

## 下载

- Windows x64 安装版:`Coopanion-Setup-0.2.15.exe`
- Windows x64 便携版:`Coopanion-0.2.15-win-x64-portable.zip`
- Apple 芯片 Mac:`Coopanion-0.2.15-mac-arm64.dmg` / `.zip`
- Intel Mac:`Coopanion-0.2.15-mac-x64.dmg` / `.zip`
- Linux x64:`Coopanion-0.2.15-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`:八个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`:自动更新读的版本信息，不用下载。

Windows 安装版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。除简体中文和英文外的译文由模型翻译，欢迎提 PR 修正。
