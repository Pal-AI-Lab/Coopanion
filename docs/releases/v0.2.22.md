# Coopanion v0.2.22

**用 Gemini / 豆包上游时 Coo 可以接受语音输入;Windows on Arm 有原生的安装版和便携版;台词气泡和输入气泡可以分别设停留时间**

## 新功能

- **Coo 能听到你的原声**:现在，用 Gemini / 豆包上游时，Coo 可以接受语音输入(原生多模态理解),你可以唱歌给 Coo 听，或者让 Coo 纠正你的外语口语。语音输入原先只把识别出的文字交给模型;当前端点是开了多模态的 Gemini 协议端点或豆包端点时，每批语音的录音会和识别出的文字一起发送给模型服务。默认开启;不想发送录音，在「语音输入」页关闭「投递录音」;只想发送录音，关闭「投递转写」;一批录音超过「录音上限」时只发送文字。用不支持音频输入的豆包型号时，请关闭「投递录音」。
- **Windows on Arm 原生版**:新增 Windows on Arm 的安装版和便携版，Arm 电脑上不用再经 x64 仿真运行。已经装着 x64 版的 Arm 电脑照常自动更新到 x64 版。少数自己录音或放音的扩展暂时装不进原生版，需要时请继续用 x64 版。
- **台词气泡和输入气泡分别设停留时间**:习惯页的「台词停留时间」和「输入气泡停留时间」各可选「自动」或固定 1–60 秒;台词后面排着提问或引导时，固定档按自动档的时长收起(感谢 @leafliber)。

## 修复

- **Gemini 端点上旧的 PDF 挤掉新截图**:早先发过的 PDF 和文本附件不再每次请求都跟着发，Coo 新截的屏能正常看到;附件不再在发送前被丢掉，模型服务拒收时去掉附件重发一次(感谢 @leafliber 的复现)。
- **Coo 戴礼帽时摸不到帽顶**:在帽顶上来回划也算摸摸，点帽顶能戳到、能拎起(感谢 @leafliber)。
- **瘦高的形象走不到屏幕边**:Live2D 全身模型这类比 Coo 窄的形象，现在能走到屏幕边上，悬停按钮也贴着身体(感谢 @kwk1001、@AKIs-z01,#744)。
- **Coo 靠在屏幕右侧时，右键菜单和悬停按钮左右排得不一样**:两处的按钮现在排法一致(感谢 @kwk1001)。
- **设置窗口**:隐藏或显示左栏的 World 时，其余状态灯不再闪一下;左栏折叠时名字和扩展图标原地淡入淡出，不再跳到别处(感谢 @kwk1001)。

## 改动

- **cortico 子模块升到 v0.2.17**:用量账本很大时，查看今天的花费不再耗尽内存、让应用退出(感谢 @milan-fu,Pal-AI-Lab/Cortico#421);会话历史里有写到一半的工具调用时，llama.cpp 等模型服务不再拒收整条请求(感谢 @jcs130)。

- Windows on Arm 安装版:`Coopanion-Setup-0.2.22-arm64.exe`

- Linux x64:`Coopanion-0.2.22-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`:十个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-arm64.yml`、`latest-linux.yml`:自动更新读的版本信息，不用下载。

Windows x64 安装版和 AppImage 会自动更新到这个版本;Windows on Arm 安装版从这个版本起，随之后的版本自动更新。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。除简体中文和英文外的译文由模型翻译，欢迎提 PR 修正。
