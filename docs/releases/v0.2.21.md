# Coopanion v0.2.21

**右键菜单只放固定的悬停按钮;桌宠可以不盖住任务栏、不出现在截图和录屏里;扩展事件的时间按部署时区显示**

## 新功能

- **右键菜单只放固定的悬停按钮**:右键 Coo 出现的按钮和鼠标停在 Coo 身上出现的是同一组(最多 6 个),另有设置、暂停 / 继续和退出;没有固定的动作不再列在右键菜单里。在习惯页的「悬停按钮」里修改。悬停按钮仍是默认那两个的旧安装，更新后 Coo 会告知一次(感谢 @kwk1001)。
- **开局引导里挑选悬停按钮**:引导里多了一步多选卡片，选中的按钮立刻生效，可以一个都不选(感谢 @kwk1001)。
- **「显示在任务栏上」开关**(Windows):在习惯页的「显示」里，默认打开。关闭后 Coo 只显示在任务栏上沿以上，坐下时垂下的腿不盖住任务栏(感谢 @consider27,#725)。
- **「不出现在截图和录屏里」开关**(Windows):在习惯页的「显示」里，默认关闭。开着时 Coo 不出现在截图、录屏、直播和 Coo 自己的截屏里;开着时 NVIDIA 即时重放的桌面捕获可能无法开启(感谢 @FelixHenrikChristian,#723)。
- **Gemini 端点接收音频和视频附件**:开了多模态的 Gemini 协议端点把音频、视频、PDF 和纯文本附件发给模型，单次请求合计不超过 18 MiB。桌宠的语音输入仍只把转写的文字交给模型(感谢 @Ashley-QwQ)。

## 修复

- **扩展发来的事件时间早 8 小时**:扩展用 UTC 时间戳发事件时，Coo 读到的每批事件时间和设置窗口里的投递时间现在按部署时区显示;更新前已经保存的事件不变(感谢 @Lostdegree,#724)。
- **Minecraft 连外部服务器时点了「断开」,重启后又自动连接**:断开和连接的选择现在会保存。对面没有开服时，重连失败从第二次起不再单独叫醒 Coo(感谢 @konakonazydxn-svg,Pal-AI-Lab/Cortico#412)。
- **用量账本很大时打开用量页，Coo 会卡住**:账本改成分块读取，读取期间事件照常投递(感谢 @jcs130,Pal-AI-Lab/Cortico#406)。
- **形象包运行失败时查不到原因**:原因现在显示在对话页的那一行，并写进运行日志和 `GET /api/figures/status` 的 `problems`(感谢 @fateSSD,#717)。
- **开局引导每一步之间停顿 5 秒以上**:气泡出现时鼠标已经在气泡的位置不再算作悬停，把鼠标移进气泡才会让气泡停留(感谢 @leafliber)。
- **Claude 协议端点收到音频附件时整个请求失败**:不支持的附件类型现在跳过，只保留文字行(感谢 @Ashley-QwQ)。

## 改动

- **cortico 子模块升到 v0.2.16**:音频和视频附件按各自的类型保存，取回时类型不变(感谢 @Ashley-QwQ)。
