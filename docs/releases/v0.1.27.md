# Coopanion v0.1.27

**ChatGPT 套餐登录修复，系统代理传给 Core,说话键读不到时不再一直收音**

## 修复

- **ChatGPT 套餐登录**:从 v0.1.25 起，用套餐登录后，凡是有回复内容的请求都会失败，提示连接或响应流失败。原因是套餐路线在请求结束时给出的输出列表是空的，没通过 Coopanion 的格式校验。现在按流里已经完成的内容补齐。仍然没有用真实账号验证，继续标为「测试中」。
- **说话键读不到时不再一直收音**:macOS 没有授权「输入监控」等情况下读不到说话键时，以前会自动改成一直收音，周围的声音会被识别后发给 Coo。现在保持你选的收音方式，暂不识别说话，并在提示里写明原因。想一直收音，可以在语音设置里选「一直听」。
- **对话页的空头像行**:Coo 这一轮没有说话时，对话页不再留下一条只有头像的空行。
- **系统提示词页的保存**:同时保存多份时，其中一份失败不会再漏掉后面几份。「立即应用」后，没有改动的段换成最新内容，正在编辑的段保留你的改动和撤销记录。

## 新功能

- **系统代理**:Core 启动前读取系统的代理设置(包括 PAC 脚本),模型请求、检查扩展更新和安装扩展都会走这个代理。你自己设置了 `HTTP_PROXY`/`HTTPS_PROXY` 环境变量时，以你的设置为准。只支持 HTTP 和 HTTPS 代理，SOCKS 代理仍然直连。
- **扩展页可以填写 npm 源**(高级模式):填写后写进扩展目录的 `.npmrc`,搜索、检查更新和安装都使用这个源。连接失败时显示具体原因。
- **系统提示词页的编辑**:支持撤销和重做，可以按段折叠(第一次打开只展开 CONSTITUTION),变量可以单击查看、用方向键选择、按 Enter 或拖动插入，每一段可以单独预览变量替换后的效果。

## 改动

- **系统提示词页**:「重载当前 session」改名为「立即应用」,「清空重开」改名为「清空对话并重开」。高级模式里可以从变量直接跳到对应 World 的配置。
- **连接失败的提示**:所在地区不受支持时，说明原因并附上支持地区的链接;服务已经应答但响应格式无法读取时单独说明。这两种情况不再一律提示检查密钥。
- **占位推理**:DeepSeek 照旧在工具调用前补一条占位推理;通过 OpenRouter 连接时不再补。如果服务商因此拒绝请求，桌宠会请你把情况反馈给开发者。
- cortico 子模块升到 v0.1.16。
