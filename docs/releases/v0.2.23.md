# Coopanion v0.2.23

**Gemini 的默认模型改为 gemini-4-hydrogen;对话页可以一键回到底部;World 设置页可以直接打开扩展详情**

## 新功能

- **Gemini 4 型号**:Gemini 的默认模型改为 `gemini-4-hydrogen`,推荐型号里加入 `gemini-4-argon`、`gemini-4-carbon`、`gemini-4-neon`。四个型号都按多模态处理(能看图、能听「投递录音」发去的录音),都有内置价目;`gemini-4-hydrogen` 和 `gemini-4-neon` 的思考强度可以到最高一档。已经建好的 Gemini 端点不会自动修改：想换成 Gemini 4,请修改端点的型号并打开多模态。新默认比原来的默认 `gemini-3.5-flash-lite` 贵：输入每百万 token 0.30 → 1.50 美元，输出 2.50 → 7.50 美元。
- **对话页「回到底部」**:在设置窗口的对话页往上翻看更早的消息后，输入框上方出现「↓ 回到底部」,点击回到最新的消息(感谢 @tokc2327-code)。
- **World 设置页直接打开扩展详情**:World 设置页的标题旁多了一个 ⓘ,点击打开这个扩展的详情;关闭后回到原来的页面，还没保存的设置仍在(感谢 @kwk1001、@AKIs-z01,#754)。

## 修复

- **开局引导里的过渡台词停留过久**:点完确认后的那句台词有时要停约 7 秒才收起。鼠标位置的回报中断一下之后，停在气泡位置的鼠标被当成了移入气泡;现在按正常的时长收起。
- **设置窗口里叠着两层弹窗时按 Esc**:只关闭最上面一层(感谢 @kwk1001)。
