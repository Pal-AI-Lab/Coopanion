# Coopanion v0.2.5

**说话声，气泡速度可调，闹钟列表，形象包可以自定义移动方式**

## 新功能

- **说话声**:「习惯」页新增「说话声」分区。开启后，Coo 的气泡每打出一个音节，就念一个短促的音节，代替「说话」类的叽咕声，跟着这一类音效的开关走。音高、语速各有低、中、高三档，也可以自定义数值。默认关闭。中文按拼音念，英语查发音词典，日语的汉字查读音词表，法、德、西、葡、意、俄按读音规则，韩语按收音连读。
- **气泡速度**:「习惯」页「显示」分区多了一个「气泡速度」滑块，0.5–2 倍，Coo 气泡的打字速度和停留时间按倍率缩放，可以用来配合语音扩展的语速。Coo 不能自己改这一项。
- **闹钟列表**:高级模式的「应用通知」页列出 Coo 给自己设的闹钟，可以删除，删除后 Coo 会收到通知。
- **阶跃 Step Plan**:模型服务新增「阶跃 Step Plan」,走 Step Plan 套餐的端点，默认模型 `step-5-preview`。感谢 @Cznorth 的贡献。
- **形象包可以自定义移动方式**:让 Coo 走动的工具改名为 `pet_move_to`。形象包可以在 `figure.json` 里用 `moves` 声明自己的移动目标，声明 `needs: ["windows"]` 后能拿到屏幕上窗口顶边的位置，比如做成站到窗口上。官方的 Coo 和大肥鱼不用这个能力，行为不变。写法见桌宠包 README 的「形象包」一节。读窗口在 Windows 上实测过，macOS 和 Linux(X11)还没有实测。

## 修复

- **切换菜单后草稿丢失**:对话页和高级模式 Live 页的输入框里没发出去的文字和图片，切到别的菜单、关掉窗口再回来都还在，发送后清掉(#247)。
- **ChatGPT 套餐把可选参数当成必填**:经 ChatGPT 套餐调用工具时，可选参数不再被要求必填，Coo 不会再给它们填占位值。
- **数据页同名存储项互相串**:两个扩展用了同一个存储名时，「数据」页不再显示对方的内容，清空也只清自己的(#259)。
- **托盘图标残留、任务栏按钮空白**:点「重启更新」后，旧的托盘图标会先撤掉再安装;设置窗口的任务栏按钮改用正在运行的程序自己的图标。
- **自述和实际能力矛盾**:六套出厂人设的自述原来说「听得见、看得见屏幕」,和默认关闭的电脑操作冲突。现在改为以环境说明为准，关着的就照实说。中文里称呼使用者改用「ta」。没改过的旧版自述下次启动时自动换成新版，改过的不动。

## 改动

- **cortico 子模块升到 v0.2.4**:扩展的 World 实例 id 和定义不一致时加载失败并写明原因;前缀里文件很多的目录折成一行。
- Coo 模型服务扩展包带上了图标。
- 桌宠包 README 写明形象包的沙箱只允许脚本和图片，不支持视频。
- 说话声用到的发音词典与读音数据的来源和许可见桌宠包的 `THIRD_PARTY_NOTICES.md`。

Windows 安装版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。除简体中文和英文外的译文由模型翻译，欢迎提 PR 修正。
