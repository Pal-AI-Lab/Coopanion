# Coopanion v0.2.7

**可以给 Coo 改名，对话页有上下文圆环，导入的形象包可以卸载，大肥鱼有了店员装;关掉代理软件后不用重启也能连上，关掉的功能当场回收内存，一批安全修复**

## 新功能

- **Coo 的名字**:「习惯」页「通用」里新增「Coo 的名字」。改名后桌宠右键菜单顶部、电脑操作的授权问句和对话页当场跟上;清空后恢复为 Coo(#320)。
- **上下文圆环**:对话页输入框里、发送键左边多了一个小圆环，显示离整理之前的对话还有多远。鼠标停在上面能看到当前约多少 token、到多少时整理，以及上次整理的时间;整理进行中圆环会转(#318)。
- **卸载导入的形象包**:装扮页里自己导入的形象包，鼠标停在卡片上时右上角有垃圾桶，确认后删除。删的是正在用的形象时换回 Coo。内置形象(Coo、大肥鱼)和创意工坊里的包不能在这里删(#317)。
- **大肥鱼的店员装**:大肥鱼加了第三套服装「店员装」,在装扮页的服装一栏选择(#315)。
- **用量与成本页改版**:页面按节重排，新增 Token 活跃度格子图，按天显示用了多少 token,范围之前约一年的格子淡显作对照;分段按钮的选中项改为滑动切换(#299)。
- **系统提示词页**:去掉右栏，模板变量移到各段的标签下面(#308)。

## 修复

- **开着代理才能连上，关掉代理就连不上**:之前 Coopanion 只在启动时读一次系统代理，并且所有网站都用同一个结果。启动时代理软件开着、之后关掉，Coo 的请求会一直发往已经关掉的代理端口，直到重启。现在每次请求都按当时的系统设置和目标网站决定走不走代理，打开或关掉代理软件不用重启(#331)。
- **关掉的功能当场回收内存**:关掉语音输入后，识别模型当场释放(SenseVoice 约 240 MB、Whisper small 约 375 MB);关掉电脑操作后，它的后台进程当场结束;关闭设置窗口后窗口占的内存一并释放，下次打开回到关闭时的页面，有没保存的修改时仍只是隐藏(#298、#312)。
- **电脑操作卡住**:后台进程没有响应时会被换掉，下一步自动起一个新的，不再一直超时;点击和局部放大的坐标不会越出屏幕(#312)。
- **设置没存上却显示成已改**:电脑操作的设置写入失败时，开关回到实际保存的值(#312)。
- **每日闹钟遇到夏令时会偏**:每日闹钟按当地时刻安排，跨夏令时也停在设定的时刻(#312)。
- **状态文件损坏导致启动失败**:使用统计、更新记录或闹钟文件损坏时，Coopanion 会把坏文件留作 `.bad` 后重建，照常启动;闹钟文件里只有个别记录不对时，只丢掉那几条(#307)。
- **扩展装不上**:数据目录在 exFAT、FAT 或网络共享上时，安装扩展会报 EISDIR,现在可以正常安装(#301)。
- **退出和重启**:退出或重启时会等后台进程真正结束再继续，不再把正常的重启记成崩溃;选择数据目录时写入失败会给出提示后退出，不会留下没有窗口的进程(#311)。

## 安全

- **远程模型地址只能用 https**:http 不加密，API Key 和对话会明文传输。本机和局域网的地址仍然可以用 http;之前存下的 http 远程地址，请求会在发出前失败(#327)。
- **电脑操作的高风险输入每次都问**:带 Win 键的组合键、打开终端或任务管理器的快捷键，以及在终端窗口里打字或按回车，在本轮授权之后还会单独再问一次，问句里写明要按的键和要输入的内容(#319)。
- **模型地址发生跳转时请求直接失败**:服务的地址改了、会跳到新地址的，请在设置里换成新地址(#325)。
- **导入同名形象包要先确认**:导入的包和已装的同名时，先列出来，确认后才替换(#306)。
- 修复了几处与本机网页、形象包、设置窗口和安装器有关的安全问题，建议尽快更新(#306、#316、#321、#322、#323、#325)。

## 改动

- **每日闹钟的存法**:每日闹钟会额外记下设定的时刻。旧的闹钟在第一次读取时自动补上，不用做什么;之前已经被夏令时挪偏的闹钟，删掉重设一次才能回到原来的时刻(#312)。
- 界面文字里指 Coo 的「它」等代词，11 种语言里都改成直接写 Coo(#324)。
- **cortico 子模块升到 v0.2.6**:B 站直播间可以在浏览器里确认登录，新增视频排队组件;用量页改版;一批安全修复。
