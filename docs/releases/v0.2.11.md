# Coopanion v0.2.11

**修复 v0.2.7 起接 DeepSeek 等 Responses 接口时首句就报 `SSE line longer than 196608 characters`，以及扩展清单带 BOM 时 Core 起不来**

## 修复

- **接 DeepSeek 时首句报 `SSE line longer than 196608 characters`**(v0.2.7 起):系统提示词加上工具定义较长时,Responses 接口会把它们随事件原样回显,超过 v0.2.7 设的单行上限,调低最大输出只会让上限更小。现在不再设这个上限;失控的输出仍按输出字数中止。
- **扩展清单带 BOM 时 Core 启动即退出、每 4 秒重试一次**:由别的脚本(如 PowerShell 5.1 的 `Set-Content -Encoding UTF8`)改写过的 `extensions/package.json` 以 BOM 开头,Core 解析不了。现在按 BOM 读取;清单解析失败时错误里带文件路径。扩展页整块标红、检查更新失败是同一根因。

## 改动

- **cortico 子模块升到 main fa57ab19**:除上面两项,内置的网页搜索 World 可以切到 DeepSeek 搜索,多了「快速配置」页签填密钥、试搜一次。
