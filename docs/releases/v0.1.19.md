# Coopanion v0.1.19

**控制台里的桌宠预览重新显示,帧率可以调到 120、144 或不限,桌宠最大可以放到 1000%**

## 新功能

- **更高的帧率**:「习惯」页新增「帧率」,可选 60、120、144 和不限(跟随显示器刷新率)。Coo 走动、被拎着、跳起时按选的帧率画;打开「一直按这个帧率画」后,站着、坐着、睡着时也按这个帧率,关着时静止降到每秒 30 帧。帧率超过显示器刷新率时按显示器的;帧率越高越费 CPU 和显卡。
- **更大的桌宠**:大小上限从 200% 提高到 1000%。大小滑条在 200% 处有一条分界线,右边一小段对应 200%–1000%;拖过分界线后这一段会拉长,方便细调,拖回 200% 以内再收回去。方向键、Page Up/Down、Home/End 也能调。Coo 自己调大小时可选的范围同样到 1000%,仍会先问你。

## 修复

- **「开始」页和「装扮」页的桌宠预览一片空白**:v0.1.16 起 Coo 和大肥鱼都画在形象包的独立页面里,这个页面只允许桌宠自己的页面嵌入,控制台在另一个端口,预览因此显示不出来。现在本机的控制台也可以嵌入它。

## 下载

- Windows x64:`Coopanion-Setup-0.1.19.exe`
- Apple 芯片 Mac:`Coopanion-0.1.19-mac-arm64.dmg` / `.zip`
- Intel Mac:`Coopanion-0.1.19-mac-x64.dmg` / `.zip`
- Linux x64:`Coopanion-0.1.19-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`:七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`:自动更新读的版本信息,不用下载。

Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证,第一次打开的方法见 README。
