# Coopanion v0.2.18

**开局引导可以退回上一步;电脑操作能按住键和鼠标键;可以选择具体的麦克风**

## 新功能

- **开局引导可以退回上一步**:语言页之后的每个问题，气泡左上角都有「上一步」,回到前一个问题时显示当时的回答，可以重新选择。
- **电脑操作能按住**:Coo 可以按住一个键或组合键最多 30 秒，也可以按下、松开鼠标键来拖动;一轮结束时还按着的键和鼠标键都会松开(感谢 @hina885,#612)。
- **形象包音效的 `repeat`**:`figure.json` 里的音效可以设定上一次还没放完时又被触发怎么放:`restart` 打断后从头放,`finish` 不放这一次,`overlap`(默认)叠着放(感谢 @as124da1231,#596)。
- **选择具体的麦克风**:「语音输入」页的麦克风下拉列出每个输入设备;所选设备拔掉或不在时改用系统默认设备(感谢 @leafliber、@Lantichr,#591)。

## 修复

- **语音输入让系统麦克风音量越来越低**:收音不再开自动增益，回声消除和降噪照旧(感谢 @leafliber、@sck6162,#592)。
- **说话键和打字键是同一个键时，按下同时开口会丢掉句首**:判定长按期间录到的声音会补进识别(感谢 @leafliber)。
- **复制粘贴时打字框被误打开**:组合键里按下的 Ctrl、Alt 不再算作一次轻点，Ctrl+C、Ctrl+V 不会触发连按两下 Ctrl 的打字键;Alt+Tab 同理(感谢 @leafliber、@wocwang,#598)。
- **截图有时到不了模型**:截图回执之后紧跟着投递了一批事件时，下一次请求仍带上截图(感谢 @leafliber、@DrPdx,#600)。
- **GNOME 上开着桌宠时，新开的窗口拿不到焦点**:GNOME 上桌宠窗口改用 dock 类型，仍然在普通窗口上面(感谢 @YGTQ-tree,#616)。
- **安装或卸载扩展时退出，可能在装卸没做完时被强制结束**:退出时先等扩展装卸做完，最多再等 65 秒(感谢 @kwk1001)。
- **「让位最多等待」没有说明**:补上说明：等满这么久你还没停手，这次操作就不执行;设为 0 时不等待(#584)。
- **设置窗口**:报错和状态提示放在触发它的控件旁边，长错误不再撑开页面;扩展市场的报错和进度跟着各自的操作;卸载的 World 在重启前不再显示运行开关和状态灯，侧栏同步(感谢 @kwk1001)。

## 改动

- **高级模式去掉旧的端点设置面板**:端点在「模型供应商」页编辑，旧的端点页链接会跳到这一页;报价照旧在端点编辑页里填写。
- **cortico 子模块升到 v0.2.13**:说话、字幕这类边输出边执行的工具，不再因为同一条回复里前面有结束本轮的工具而被记成未执行、重说一遍;Cormini 不再写入点开头的路径(如 `.git`),也不再写入经链接、短文件名或大小写别名落到工作区外的路径;获取模型列表不再要求先填模型;卸载扩展前再查一次是否在运行，关机时等扩展装卸做完。
