# Coopanion v0.1.5

本次集中修复 macOS 输入与窗口交互，统一 Coopanion 品牌，并纳入 PR #2 中仍适用的主题与代理功能。

- 修复 macOS CUA 在权限已开启时返回输入成功、实际没有文字的问题：正确释放修饰键并逐字素发送 Unicode，支持中英文、emoji、URL 与多行文字。
- 调整 macOS 桌宠窗口层级与输入焦点，避免遮挡输入法候选窗和原生选择菜单；组合输入期间 Escape 不关闭输入框。
- 减弱外发光和阴影；为 AUTO/KEY 收音模式降级补充原因提示。
- 装扮编辑器跟随控制台明暗主题，桌宠配色独立；模型请求和下载支持环境代理，本机通信自动直连。
- 应用与安装包统一命名 Coopanion，README 与左上角使用原有几何字形，开头两个 o 为绿色，并保留 C 内双圈图形标志。
- 保留旧安装的数据目录兼容。子模块修复已发布到 Pal-AI-Lab 的 fork，递归克隆可以取得完整代码。

## 下载

- Windows x64：`Coopanion-Setup-0.1.5.exe`
- Apple 芯片 Mac：`Coopanion-0.1.5-mac-arm64.dmg` / `.zip`
- Intel Mac：`Coopanion-0.1.5-mac-x64.dmg` / `.zip`
- `SHA256SUMS.txt`：五个安装文件的 SHA-256 校验值。

## macOS 升级提示

本版本仍使用临时签名，未做 Apple 公证。升级后如果系统设置里的权限开关已开启，但应用仍报告无权限，请在「隐私与安全性」的辅助功能、屏幕录制、输入监控中移除旧条目，再明确添加 `/Applications/Coopanion.app` 并重新启动。此过程不会清除应用数据。

在本机完成权限刷新后，最终安装包的英文、中文＋emoji、中文 URL、多行输入和截图均已实测通过；已完成首次设置流程手工复验。
