# Coopanion v0.2.17

**托盘里可以打开「鼠标穿透」;语音喊停能打断正在进行的电脑操作;音效有了音量**

## 新功能

- **鼠标穿透**:托盘菜单「显示桌宠」下面多了「鼠标穿透」,打开后点击都穿过 Coo 落到下面的窗口，Coo 照常走动、说话。只在这次运行里有效(感谢 @wslblwk,#557)。
- **音效音量**:习惯页「音效」加了「音量」滑条，调的是桌宠所有音效，说话声也一起变小(感谢 @zhenyuaceboss-cmd,#574)。
- **侧栏跟随「我的 World」的顺序**:在「我的 World」里拖动排序后，侧栏的 World 跟着滑到新位置(感谢 @kwk1001)。
- **点头像打开扩展信息**:「我的 World」里点头像和点名字一样打开扩展信息，名字旁的信息按钮去掉;从头像也能拖动整行(感谢 @kwk1001)。
- **模型供应商卡片可以拖动排序**,删除前用对话框确认(感谢 @kwk1001)。

## 修复

- **语音喊停打断不了电脑操作**:按说话键说的话会打断 Coo 正在进行的电脑操作和正在生成的回复;始终收音时不打断(感谢 @leafliber、@Lime809,#573)。
- **说话键和打字键是同一个键时，双击会先闪一下收音**:两个键相同时，按住超过 0.3 秒才开始收音;双击打字在第二下松开时打开打字框(感谢 @leafliber、@GotaX,#577)。
- **macOS 上桌宠挡住 App Store 的触控 ID 确认**:App Store 在前台时，桌宠降到普通层级(感谢 @leafliber、@Ericple,#547)。
- **电脑操作时被误判为使用者在用鼠标**:修了一处把早先记下的指针位移当成刚发生的问题;回执会写出挡住的是哪个信号、前台是哪个窗口(感谢 @leafliber、@Bot14onCode,#560)。
- **会话文件被杀毒、备份或同步软件短暂占用时 Coopanion 退出**:被占用时重试约 3 秒(感谢 @2251000656,#575)。
- **收尾提醒设得不小于单次唤醒上限时，提醒一次也不出现**:提醒提前到上限前一轮(#575)。
- **设置窗口**:拖动「我的 World」跟手、拖动时自动滚动;用量页控件不再跳动，金额写币种符号;下拉列表和悬停提示统一样式;扩展信息加图片栏;去掉筛选后回到原来浏览的位置;只告知的对话框只有「知道了」;负数金额写成 -¥0.20;习惯页的音效、说话声和电脑操作下注明管不到别的 World(感谢 @kwk1001)。

## 改动

- **cortico 子模块升到 v0.2.12**:WebUI 换成设置窗口的当前版本;文件被占用时重试约 3 秒;收尾提醒不小于上限时提前到上限前一轮;扩展 id 被占用时写一条 WARN;启停 World 的错误按界面语言显示;Cormini 说明附件句柄的写法。
