# Coopanion v0.2.13

**只收流式请求的模型服务在桌宠窗口断开时也能用;Windows 上高回报率鼠标不再拖慢桌宠;换系统默认麦克风不用重启**

## 修复

- **只收流式请求的模型服务**:桌宠窗口断开时，主会话改发非流式请求，只收流式请求的服务会拒绝。现在请求一律走流式，「测试连接」也走同一条路(#452)。
- **高回报率鼠标卡顿**:Windows 上桌宠不再转发每一次鼠标移动，改为每 15 毫秒读一次光标位置;1000Hz 以上的鼠标在桌宠所在屏幕上移动时，桌宠不再卡顿(#414)。
- **换系统默认麦克风**:没有指定麦克风时，系统默认输入设备变了，语音输入会跟过去，不用重启 Coopanion(#448)。
- **设置窗口里关机**:从设置窗口左栏关机后,Core 保持关闭，不再弹「Core 意外退出」并自动重启;托盘「重新启动」可以再打开(感谢 @lco117,#456)。
- **覆盖安装时提示 Coopanion 无法关闭**:电脑上的 Git 开了 fsmonitor 时，Coo 的工作区会留下一个常驻的 git 进程，安装包把它当成 Coopanion 还开着。现在 Coo 的工作区不再启用 fsmonitor(#338)。
- **某个 World 启动失败**:启动时一个 World 出错(比如端口被占)不再让 Core 反复重启;这个 World 留在未激活，高级模式「World 总览」里显示原因,Coo 也会收到一句说明。
- **电脑操作的报错**:截图或移动鼠标失败时，报错里写明可能被更高权限的窗口挡住，Coo 能直接告诉你原因(#463)。
- **扩展页下载量**:下载统计取不到时显示「—」,不再显示成 0(#450)。

## 改动

- **cortico 子模块升到 v0.2.9**:网页搜索的 Brave、DeepSeek 地址可以在「快速配置」里换成兼容的代理;Minecraft World 支持 1.21.2 以后的版本里的药水和爆炸;QQ World 的语音转写在结果还没出来时会再取几次。
