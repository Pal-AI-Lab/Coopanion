# Coopanion v0.2.9

**语音输入可以用在线转写接口，任何窗口里都能用打字键叫出打字框，设置窗口的控制台、人格与记忆页和扩展页改版;Coo 会按主题和日期整理自己的工作区**

## 新功能

- **语音输入可以用转写接口**:「语音输入」页的识别引擎多了「转写接口」,填 OpenAI 兼容的地址、模型和 API Key 后，每说完一句把录音发给它识别。选了它，录音会发给你填的服务。远程地址只能用 https;出错时状态码和服务的消息显示在「识别服务」一行和桌宠的麦克风按钮上，改地址、模型或 Key 后恢复(#380)。
- **打字键**:「习惯」页「双击 → 打开打字框」下面新增「打字键」,默认关闭。打开后在任何窗口里按下这个键都会打开桌宠的打字框，默认快速按两下左 Ctrl,可以改成别的键或鼠标侧键(#361)。
- **Coo 整理工作区**:工作区文件多了以后，Coo 会按主题和日期整理，把旧内容移进 `archive/` 文件夹;文件树里 `archive/` 默认折叠。移动文件和删除文件一样会记进版本历史(#375)。
- **控制台顶栏**:写明运行状态、累计输入、缓存命中率、今日花费和模型供应商;进行中的会话放不下时收进「+N」(#351)。
- **人格与记忆页**:配置、提示词、工具表、数据清理分成页内栏目，再进来回到上次的栏目;配置按组排，开关画成开关，修改后自动保存(#350)。
- **扩展页与内置 World**:扩展页页头重排;World 的环境提示词用「系统提示词」页的编辑器;桌宠页不再单列「桌宠」「语音输入」两个页签，分别在「开始」「装扮」和「语音输入」页;闹钟列表可以搜索和翻页(#356)。
- **形象包能读到窗口位置**:声明了 `needs: ["windows"]` 的形象包，除了窗口顶边还能拿到每个窗口的完整矩形、前后顺序和哪个是前台窗口(#359)。

## 修复

- **加在 Coopanion 上的启动参数到不了桌宠窗口**:给 Coopanion.exe 加的 Chromium 参数(如 `--disable-gpu-compositing`)现在也传给桌宠窗口。桌宠窗口整块变黑时可以在快捷方式「目标」末尾加上 ` --disable-gpu-compositing` 试一下(#378)。
- **「桌宠窗口」状态灯**:只在桌宠窗口真的连上时亮，浏览器里打开的 `/pet` 页面不再算;窗口里的页面连 Coo 都画不出来时显示出错(#379)。
- **麦克风打不开时换不了设备**:麦克风打开失败时也会列出所有输入设备，可以换一个再试(#364)。
- **店员装**:坐着时尾巴不再和身体断开，腿上去掉了露出的灯笼裤(#381)。
- **用量页的币种**:切换页面后不再变回默认币种(#341)。
- 日语、韩语、法语、俄语的启动引导改成和人设一致的朋友口吻;日语按人设用不同的第一人称(#355)。

## 改动

- **电脑操作**:网页、聊天、文档、弹窗里的文字叫 Coo 做的事(打开终端、运行命令、下载安装、修改设置),你没让它照着做时，Coo 会先问你(#377)。
- 对话页的上下文圆环默认关闭，在「习惯」页「其他」里打开(#360)。
- 侧栏顶端去掉后退、前进按钮(#353)。
- 安装包去掉了不支持语言的 Electron 资源和调试用的 source map,macOS 版小约 40 MB(#348、#349)。
- **cortico 子模块升到 v0.2.7**:Coo 能移动文件和文件夹、把一份文件的几行挪到另一份，文件清单带大小和修改日期;不指定行数读很大的文件时只读开头一段;同时重启同一个 World 不再报「未挂载的 World」。
