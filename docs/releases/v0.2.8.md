# Coopanion v0.2.8

**电脑操作不再单独询问终端输入和系统快捷键**

## 改动

- **电脑操作只按「询问时机」询问**:v0.2.7 加的单独询问已撤回。按带 Win 键的组合键、打开终端或任务管理器的快捷键，以及在终端窗口里打字或按回车，不再在本轮授权之后再询问一次;在终端里连续输入命令时，不用每一行都确认。现在只按「习惯」页「电脑操作」里选的询问时机询问，和 v0.2.6 相同(#336)。

## 下载

- Windows x64 安装版:`Coopanion-Setup-0.2.8.exe`
- Windows x64 便携版:`Coopanion-0.2.8-win-x64-portable.zip`
- Apple 芯片 Mac:`Coopanion-0.2.8-mac-arm64.dmg` / `.zip`
- Intel Mac:`Coopanion-0.2.8-mac-x64.dmg` / `.zip`
- Linux x64:`Coopanion-0.2.8-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`:八个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`:自动更新读的版本信息，不用下载。

Windows 安装版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。除简体中文和英文外的译文由模型翻译，欢迎提 PR 修正。
