# Coopanion v0.1.13

**音效按类开关,双击打字可选,桌宠静止时少画几帧**

## 新功能

- **音效按类开关**:「习惯」页多了「音效」卡片。「播放音效」和 Coo 菜单里的音效按钮是同一个开关;下面能分别关掉动作、互动、表情、打呼噜、说话、按钮与提示六类声音,关掉的那类不再出声,其余照常。鼠标停在一项上能看到它包括哪些声音。「呼噜打多久」设每次睡着后打多少秒呼噜就安静下来,Z 照样飘;填 0 一直打到醒。
- **双击打字改成可选,默认关**:双击 Coo 不再打开打字框。想要原来的行为,在「习惯」页勾上「双击 Coo 打开打字框」。点 Coo 身旁的气泡按钮照样能打字。
- **锁定 60 帧**:「习惯」页「大小」下方的勾选框,默认关。勾上后 Coo 一直按每秒 60 帧画,见下面「改进」。

## 改进

- **桌宠帧率不再跟着显示器刷新率走**:原先 Coo 站着不动也按显示器刷新率每帧重画。现在走动、被拎着、跳、转身、点头、摇头、转圈时每秒 60 帧;站着、坐着、睡着时每秒 30 帧。

## 修复

- **拖到另一块显示器时 Coo 不再消失**:原先要松手窗口才挪过去,拖过屏幕边缘后 Coo 被裁掉看不见。现在拖动途中光标一到另一块显示器,窗口当场跟过去。
- **装了配置不完整的扩展时,设置照常保存**:以前某个扩展交来的配置组缺字段时,设置窗口里任何一页点保存都报 HTTP 500。现在跳过那一组并记进日志,其余设置照常保存(#52)。

## 其他变化

- **Cortico 升到 0.1.6**。
