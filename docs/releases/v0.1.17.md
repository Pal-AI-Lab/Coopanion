# Coopanion v0.1.17

**修复 Windows 版自动更新后设置全部回到初始状态**

## 修复

- **自动更新后设置、API Key、提示词和形象全部不见了(Windows)**:用安装程序一步步装、装在默认位置(`%LOCALAPPDATA%\Programs\Coopanion`)时,v0.1.14 起的自动更新会把程序装到 `%USERPROFILE%\Coopanion`,原来的 `data` 文件夹留在旧位置,新位置从头开始。旧的设置没有被删掉。现在自动更新留在原来的安装位置。(#84)
- **已经遇到这个问题的**:更新到 v0.1.17 后第一次启动时,如果新位置还没有设置,Coopanion 直接把旧位置的设置搬回来。如果更新后已经在新位置用过,会弹窗询问是否换回更新前的设置。选「换回更新前的设置」,Coopanion 重启一次后换回,现在这份改名为 `data-replaced-<时间>` 留在安装文件夹里,不会删除。选「继续用现在的」,以后不再询问,旧设置仍留在 `%LOCALAPPDATA%\Programs\Coopanion\data`。
