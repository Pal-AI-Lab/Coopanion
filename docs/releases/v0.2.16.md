# Coopanion v0.2.16

**我的 World 和扩展市场合成一页，市场标签可以排除；拖到缩放不同的副屏时桌宠不再沉到屏幕下方；带 BOM 的配置文件不再让 Coopanion 起不来**

## 新功能

- **我的 World 和扩展市场合成一页**:「World 扩展」的两个页签在同一页里切换。切到扩展市场时，World 收成左侧一列图标，新装的扩展会飞进这一列。World 可以分组、拖动排序，名字旁的按钮打开扩展信息，有新版本时名字旁会提示(感谢 @kwk1001,#524)。
- **扩展市场的标签**:左侧按功能分类;「推荐」里的认证和官方二选一，新品单独开关;系列标签用来选中;注意事项(包括需额外安装、需要密钥、本地模型)用来排除，排除会一直保存。已选和已排除的条件列在卡片上方，点一下就去掉。卡片上的标签也能点，注意事项标签点了是排除。没有结果时 Coo 会出来说一句。
- **新配色「奶Coo」**:身体固定黑色，C 的内圈填黄，眼圈里填黑。
- **形象包导入不限体积**:超过 128 MB 时，确认框里会提示包很大。

## 修复

- **带 BOM 的配置文件让 Coopanion 起不来**:config.json 等文本文件带 UTF-8 BOM 或存成 UTF-16 LE 时也能读，Core 不再因此退出(感谢 @kelibin,#520)。
- **拖到缩放不同的副屏，桌宠沉到屏幕下方**:Windows 上主屏和副屏的缩放比例不同时，把桌宠拖到另一块屏幕，窗口不再被放大、一半留在原来那块屏幕上(感谢 @Hoshino-tyut,#453)。
- **隐藏桌宠后看不到电脑操作的确认**:桌宠隐藏时，「允许操作电脑」的确认改用系统对话框(感谢 @hoiyixi,#527)。
- **删掉的扩展还留在已安装列表**:装卸扩展时，包的构建脚本要用的 node 由应用自带的运行时提供，电脑上没装 Node.js 也能正常装卸(感谢 @Bot14onCode,#486)。
- **装扮页形象名字太长压到旁边的卡片**:名字最多折两行，悬停看全名(感谢 @DanieleWolfHOLO,#529)。
- **刚装好的扩展显示英文名**:还没重启进程的扩展，也按界面语言显示名字。
- **语音识别丢掉正常的话**:只丢弃视频片尾字幕的原句，提到订阅、转发的话照常送达。
- **macOS 标题栏的分隔线**:和展开的侧栏右边线对齐(感谢 @kwk1001)。
- **界面文案**:扩展页补齐九种语言;动作按钮统一用双字动词;指 Coo 的地方不再写成「本 Bot」。

## 改动

- **cortico 子模块升到 v0.2.11**:读整份文本文件时认 UTF-8 BOM 与 UTF-16 LE;Minecraft World 的物品字段要求写英文 id,写成中文名时解析会退回并说明;已装扩展的显示名按界面语言取。
