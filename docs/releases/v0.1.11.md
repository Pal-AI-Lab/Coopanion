# Coopanion v0.1.11

**记住位置,多显示器,出错时 Coo 会说原因**

## 新功能

- **记住位置**:设置窗口「习惯」页勾上「记住位置」后,退出应用时记下 Coo 的横向位置,下次启动落回那里。默认关闭。接了多块屏幕时只记横向的比例,启动时 Coo 总在主屏上;用任务管理器结束进程、断电或崩溃时不会保存。
- **多显示器**:拎着 Coo 拖到另一块屏幕上松手,桌宠窗口跟着挪过去,Coo 从松手的地方落下。走路只在当前这块屏幕上走;拔掉 Coo 所在的显示器时回到主屏。
- **「对话」页进普通模式**:设置窗口左栏「用量与成本」下面多了「对话」页,能看到 Coo 当前这段对话的记录,包括你打的字、说的话、戳它的动作,以及 Coo 的思考和动作;下面的输入框也能直接和 Coo 说话。上下文太长时 Coo 会把之前的内容整理成笔记重新开始,整理之前的部分在这一页看不到。
- **操作电脑时不容易被中途打断**:Coo 每次被唤醒后最多请求模型的次数从 12 次放宽到 40 次,第 20 次起提醒它收尾。两个数可以在高级模式的 Cormini 页改,重启后生效。

## 修复

- **Windows:鼠标停在 Coo 身上时,浏览器里的视频画面不再停住**。原因是浏览器把铺满屏幕的桌宠窗口当成了挡住自己的窗口,就停止绘制画面。现在桌宠窗口在 Windows 上标成工具窗口,附带的变化是它不再出现在 Alt+Tab 里。
- **模型连不上时 Coo 会说出原因**:请求模型连续失败 5 次时,Coo 在气泡里说出错误码和服务商返回的原因,并给一个「打开设置」按钮。
- **大肥鱼不会再整只消失**:显卡出错导致大肥鱼画面丢失时,等显卡恢复后会自动重画回来,不用重启应用;来回切换 Coo 和大肥鱼时,旧形象占用的显卡资源会立即释放,不会切多了以后画面变空白。
- **开麦失败时麦克风会关掉**:打开语音中途出错时,已经打开的麦克风会关掉,系统的录音指示灯不再一直亮着。
- **人设里的「可缇」不会被改掉**:以前每次启动都会把自述和名字里出现的「可缇」替换成 Coo,现在不再改动你写的人设。
- **省一些模型调用**:摸头、拎起来、放下不再单独让 Coo 开口,等下一次一起告诉它;戳一下仍然会马上叫醒它。用内置的模型服务时,较早的屏幕截图只保留一行文字说明,不再每次请求都重新发送图片。
- **长时间运行更省内存**:打开设置窗口的「对话」页时,不再把有史以来的全部事件记录读进内存,只读最近的部分。

## 其他变化

- **设置窗口同步 Cortico 最新界面**:「对话」「用量与成本」「运行诊断」三页的信息排列和文案重新整理。用量页多了按模型连接分的表,未计价的调用会标出来;运行诊断页可以直接导出诊断包。
- **排查数位板问题**:桌宠窗口每次在「接收鼠标」和「点击穿透」之间切换时,往运行日志里记一行,最多每秒一行。用数位板遇到悬停失灵的话,复现后在「运行诊断」页导出诊断包发给我们。
- **匿名使用统计**:请求失败改为按请求计数,并记下失败的 HTTP 状态码;Core 崩溃时记下出错位置(程序内的文件和行号)。错误信息原文不发送。全部字段见 [docs/TELEMETRY.md](https://github.com/Pal-AI-Lab/Coopanion/blob/main/docs/TELEMETRY.md)。
