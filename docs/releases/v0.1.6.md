# Coopanion v0.1.6

桌宠多了一个形象:**DeepSeek 大肥鱼**。

- 设置窗口「装扮」页最上面一行「形象」:选「DeepSeek 大肥鱼」,屏幕底边的桌宠立刻换成大肥鱼;选「Coo」换回来。选择会保存,下次启动还是大肥鱼。
- 大肥鱼是 Live2D 式分件模型:走、跑、跳、坐下、睡觉、被鼠标拎起来甩、转身、眨眼、跟着鼠标看,十几种表情;头发、裙摆、尾巴、鲸鱼鳍和呆毛随动作晃动。倾听、点头、打瞌睡时低头歪头,脚不离地;睡觉冒出的 z 跟着配色变色。
- 八套配色:DeepSeek(原版)、DeepSeek Harness(纯黑)、ChatGPT、Claude、Gemini、千问、Kimi、MiniMax,每套按对应厂商标志配色,围裙上印着那家的标志。选了大肥鱼以后「装扮」页下面一行就是配色,点一下渐变过去。
- 大肥鱼的贴图只在第一次选这个形象时加载,只加载选中的那套配色;一直用 Coo 不会多占资源。

贴图由 ChatGPT 按参考图生成后拆件。角色原设「溟月」(上善无形),DeepSeek 女仆装二创参考 ZipZipPipe。
围裙上的标志归各自的公司所有,只用来标明配色对应哪一家,与这些公司没有关联。
