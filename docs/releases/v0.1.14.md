# Coopanion v0.1.14

**自动更新,Coo 知道现在几点、能给自己设唤醒,大肥鱼多了 5 个动作和 9 个表情**

## 新功能

- **自动更新**:Windows 版和 Linux 的 AppImage 会在后台从 GitHub 下载新版本。发现新版本时 Coo 在气泡里告诉你;下好后问你要不要现在重启更新,不急的话下次退出应用时自动装上。GitHub 下载卡住或失败时,气泡里有「去 GitHub 下载」,可以手动下载安装。Mac 版(临时签名,装不了自动更新)和 deb 仍按设置窗口左上角的提示手动下载。这个版本本身还要手动装一次,之后的版本才会自动更新。
- **Coo 知道现在几点**:你打字、说话、戳它、回答它时,Coo 收到的消息都带着你这边的本地时间;每次启动后的第一条和过了零点后的第一条还带日期和星期。
- **Coo 能给自己设唤醒**:Coo 可以给自己定时,比如答应你半小时后提醒你、每天早上打个招呼,到点它会自己醒来。唤醒只在 Coo 那边,设置窗口里不显示。应用关着时到点的,下次打开时送到,Coo 会知道原定是几点。
- **新动作和表情**:大肥鱼和 Coo 都多了 5 个动作:招手、鞠躬、发抖、扑腾、跳舞,还有 9 个表情:得意、嘟嘴、担心、认真、慌张、害怕、期待(星星眼)、大哭、疑惑。跳舞时头顶冒音符。
- **说话键的按法可选**:「语音输入」页的说话键旁边多了按法选择:「双击再按住」(默认)或「直接按住」。Coo 身旁麦克风按钮的角标显示当前的说话键,比如 `ALT×2`、`F8`。
- **更新后 Coo 会讲新版本的变化**:更新到新版本后,Coo 会读到这份更新说明,挑你用得上的告诉你。这个版本是第一次,从这个版本以后的更新都会这样。
- **Coo 知道你改了设置**:你在设置窗口或 Coo 的菜单里改了称呼、形象和装扮、大小、黑白模式、走动、音效、语音输入或电脑操作,Coo 会知道改了什么,并有所回应。连着改好几项会合成一次告诉它,改回原样不会打扰它。
- **Coo 记得启动引导里聊了什么**:引导结束后,Coo 会拿到引导里的全部对话,包括你中途关掉的情况;你填的 API Key 不会出现在里面。

## 改进

- **大肥鱼的点头和摇头**:点头是真的低头两下,摇头是脸左右转,刘海、后发和呆毛跟着甩。原来往下看、睡觉、难过时脸其实是往上抬的,现在改成低头。
- **大哭时两只眼睛都掉泪**。
- **启动时面朝屏幕中间**:Coo 站在屏幕右半边时,启动后朝左,不再总是朝右。

## 修复

- **没有可用 WebGL 的机器上大肥鱼不显示**:有些 Intel Mac 的显卡被浏览器内核屏蔽,大肥鱼画不出来,切回 Coo 还会卡住不动。现在会改用软件渲染;仍然画不出来时自动换回 Coo,不会卡住。
- **走路被打断时不再空等**:Coo 走在路上被转身、鞠躬等动作打断时,会马上知道没走到,不再等 30 秒。

## 其他变化

- **匿名使用统计多报几项设置**:音效和各类音效开关、黑白模式、大小、悬停按钮、双击打字、锁定 60 帧、记住位置、语音识别引擎、收音方式和说话键,以及「怎么称呼你」是否改过。称呼只报改没改过,不报名字。全部字段见 [docs/TELEMETRY.md](https://github.com/Pal-AI-Lab/Coopanion/blob/main/docs/TELEMETRY.md),在「习惯」页可以关掉。
- **README 分成英文和简体中文两份**。
