# Coopanion v0.1.12

**电脑操作进普通模式,清空重开,大肥鱼的主题色**

## 新功能

- **「电脑操作」页进普通模式**:设置窗口左栏「语音输入」下面多了「电脑操作」页。这一页能做四件事:开关电脑操作,允许或禁止动鼠标键盘,在「什么时候先问你」里选四档之一(每轮都问 / 动手前问 / 问一次 / 不问),选「问一次」时改「同意管多久」。让位时长、截图尺寸等其余参数仍在高级模式的「电脑操作」World 页。
- **清空重开**:「系统提示词」页「重载当前 session」旁边多了「清空重开」按钮。确认后 Coo 忘掉当前这段对话的上下文,按现在的系统提示词从头开始,不能撤销;工作区里的记忆和人设都保留。「重载当前 session」只换系统提示词、保留对话,两个按钮按需要选。
- **大肥鱼的主题色**:装扮页把桌宠换成大肥鱼的某套配色时,设置窗口跟着换成同色系的主题色,包括按钮、选中项、图表和装扮页里的选中框。八套配色各有浅色和深色两版,大面积的底色仍是中性灰;换回 Coo 回到原来的绿色。这八套方案也出现在高级模式「设置」页的「外观」里。在那里自己选过别的配色方案的话,换装扮不会改掉你的选择,重新选回绿色或大肥鱼的方案后恢复跟随。

## 修复

- **等待界面加载不再先问你**:Coo 操作电脑时等界面加载的那一步(`cua_wait`)不再弹气泡问你。「每轮都问」档下这一轮你还没同意看屏幕时,它只等待、不截图;其余三档照常在等待后附一张截图。
