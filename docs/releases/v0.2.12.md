# Coopanion v0.2.12

**打字框可以粘贴图片，语音输入页可以拖动说话门槛，音效按 Coo 的位置分左右声道;设置窗口统一了标题栏和页面布局，用量页改用实时汇率**

## 新功能

- **打字框粘贴图片**:桌宠的打字框可以粘贴图片，最多 4 张，按对话页的规则缩小;「在对话页继续编辑」会把图片一起带过去(#430)。
- **气泡悬停时不收起**:鼠标停在 Coo 的气泡上时气泡不会收起，移开后接着计时(#430)。
- **拖动说话门槛**:「语音输入」页音量条上的门槛线可以拖动，也可以选中后按方向键每次调 1 dB,松开就保存，马上按新门槛判断。门槛线只在「用说话键切换收音」和「持续收音」里显示(#435)。
- **音效分左右声道**:音效按 Coo 在所在显示器上的横向位置分到左右声道(#435)。
- **关闭使用终端和运行前的询问**:高级模式「桌宠」页「配置」页签的电脑操作里新增这个开关，默认关闭，标题用警示色。打开后，在命令行窗口里输入或按键、按 Win+R 不再单独询问，和其他操作一样按「询问时机」询问;询问时机是 never-ask 时,Coo 能不经询问执行命令(#431)。
- **用量页用实时汇率**:换算金额用实时汇率，取不到时用内置汇率;汇率只读显示在币种旁边，后面写出处和日期。原来手填的汇率不再使用。
- **设置窗口**:标题栏、页面布局和滚动统一，记住窗口大小;运行诊断页不再偏移(感谢 @kwk1001,#436)。
- **形象包**:可以做不靠地面的身体(俯视角，能走到舞台任意位置、松手后留在原地),可以自带嗓音和说话音效、跟着状态气泡的类别换表现、放大特效边距、带自己的气泡配色(#434)。

## 修复

- **勾了「接受图片输入」却不发图**:端点勾了「接受图片输入」就会发图，不再被内置服务的识图模型表否决;千问的识图模型补上 `deepseek-v4.1-flash`(#432)。
- **模型服务报错只有状态码**:服务拒绝请求时，错误里带上服务给的原因;流一开头就是错误时不再连续重试 12 次。
- **连续失败的气泡**:按状态码给建议:401、403 检查 API Key,404 检查模型名，这两种带「打开设置」;429 和 5xx 过会儿再试;其他只报状态码和服务给的原因(#438)。
- **高级模式配置页**:保存后显示服务端随这次保存改了的其他项，同组再保存不再把旧值写回(#437)。
- **副屏的窗口位置**:两块屏缩放不同时，形象包读到的副屏窗口位置整体偏移(#433)。
- **大肥鱼的裙影**:被拎起或走动时，腿上不再有一条跟着腿走的暗带(#388)。
- 「习惯」页「电脑操作」一节的说明改指高级模式「桌宠」页的「配置」页签(#432)。

## 改动

- 扩展页去掉 Bot 页签，只剩 World 和供应商(#432)。
- 更新后 Coo 会读到开发者随版本写的信，要不要转达、怎么转达由 Coo 决定(#439)。
- **cortico 子模块升到 v0.2.8**:除上面的实时汇率和报错原话，配置页保存后会重新读取取值，配置项可以标成警示色。
