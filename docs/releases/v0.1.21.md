# Coopanion v0.1.21

**「习惯」页可以按档位设回应模式和自主配置权限,大肥鱼的眉毛有了表情,修复 Mac 上大肥鱼占满 GPU、不停读写日志、数位板摸不到桌宠和坐下后眼睛卡在一条缝**

## 新功能

- **回应模式**:「习惯」页新增一行,可选安静、默认、积极和自定义。安静:互动先记着,等你说话时一起回应;默认:只有被戳的时候才回应;积极:所有互动都会回应;自定义里勾选戳一下、摸头、甩出去、拎起来放下中哪些马上回应。引导里也多了这一步。
- **自主配置权限**:「习惯」页原来的「允许 Coo 自己调整」换成禁止、默认、任意和自定义。默认和原来一样:形象、配色、走动和打呼直接改,大小、音效、主题、悬停按钮和称呼先征得你同意;自定义里逐项设。升级上来的安装按原来的开关读成默认或禁止。
- **以后都可以**:Coo 想改需要你同意的设置时,气泡里多了「以后都可以」:这次照改,这几项以后直接改,自主配置权限随之变成自定义。问句和按钮跟随界面语言。
- **大肥鱼的眉毛有了表情**:眉毛按表情抬起、压低、倾斜、拱起;难过、担心、大哭、害怕时眉头上挑,整条眉变成下凹的弯。说话时每句开头扬一下眉。刘海上透出的眉毛也更明显。

## 修复

- **Coo 不停地读写日志,没法对话**:手填的上下文上限不大于最大输出时,上下文上限算成 0,每一批对话都被强制交接,交接又唤醒下一批。现在检测到这种循环会记一条错误并停止按计数交接;保存模型连接时也不再接受上下文上限不大于最大输出。服务商资料里写明上下文上限的模型,获取模型列表后直接填上,不再提示手填。已经填错的,在高级模式的「模型」页把上下文上限清空或改大。
- **数位板快捷键让桌宠的抓手和箭头来回闪、摸不到**:数位板的快捷面板是一个键盘,按到 Ctrl+- 时桌宠窗口被缩小,鼠标判定错位。桌宠窗口的缩放现在固定为 100%,已经被缩小的启动后恢复。用笔悬停唤不醒桌宠的问题还在,可以在数位板驱动里关掉 Windows Ink。
- **大肥鱼坐下后眼睛一直半闭,或卡在一条缝**:坐着时眼睛睁开;要睡着时最后一秒多合眼,再换成睡着的闭眼。说「坐下」时醒着坐,不再停在一条缝上。犯困时眨眼变慢。
- **Mac 上大肥鱼让 GPU 占用很高、系统卡顿**:Mac 读不到桌宠身后的屏幕颜色,大肥鱼身后的光晕一直开着;v0.1.16 起这圈光晕对整个桌宠窗口做模糊,每画一帧都要重算。现在光晕只模糊身体周围一小块,样子不变。在 M2 上测,大肥鱼静止时 GPU 占用从约 40% 降到约 10%。
- 界面文字不再用性别代词称呼桌宠。
