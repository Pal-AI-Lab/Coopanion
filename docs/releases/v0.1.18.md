# Coopanion v0.1.18

**桌宠头上显示 Coo 在忙什么,修复大肥鱼丢头发和走路的腿,对话页和全屏隐藏的几处问题**

## 新功能

- **状态气泡**:Coo 想事情、翻记忆里的文件、操作电脑时,头顶的气泡里显示它在做什么,比如「在看 · 日记.md」「在点」「在定闹钟 · 18:30」,连续做同一类事会写「等 N 个」。说话、提问、打字框出现时气泡让位给对话。会显示文件名,不想显示的话可以在「习惯」页关掉「显示 Coo 在忙什么」,关掉后思考时头上照常冒思考的小圆泡。
- **扩展页可以装旧版本**:扩展详情里列出全部历史版本,每个版本都能安装,重启后生效。点扩展卡片直接打开详情;删除要点两次,第二次前会提示使用它的其他 Bot 也会受影响。

## 改进

- **扩展页检查更新失败时写出真正的原因**:以前只有一句「fetch failed」,现在会写出连的是哪个地址、底层错误是什么,比如证书和域名对不上。检查更新、搜索和详情改用和安装相同的 npm 源:在数据文件夹的 `extensions/.npmrc` 里写 `registry=<镜像地址>` 后,这几处都会走镜像,改完重启生效。
- **扩展的作者显示 package.json 里写的作者**,不再显示发布到 npm 的账号(用 GitHub Actions 发布的扩展以前会显示成「GitHub Actions」)。
- **对话页**:英文界面下,撤回失败、发图被拒的提示和戳、摸、拎的说明都是英文了。
- **Mac 上权限开着却提示没有权限**:提示里写明要先把 Coopanion 从列表里移出再加回来。更新后 macOS 不认旧版本的授权,这一步在每次更新后都可能需要。

## 修复

- **大肥鱼开一段时间后头发、刘海、尾巴和裙子不见了**:有一帧的时间间隔为 0 时,这几处的摆动会算成无效数值,从此画不出来,要重启才恢复。现在这样的帧会被跳过。如果更新后还遇到,请在 #87 里附上截图、系统版本和显卡型号。(#87)
- **大肥鱼走路时靠近屏幕的那条腿被另一条挡住**:走路和跑步时两条腿的前后关系改成和站着时一致,跑起来腰部也不再露出腿。(#90)
- **大肥鱼换配色后迟迟不变**:中途换过形象再换配色时,淡入会卡很久,新配色一直不出现,期间还多占绘制开销。(#86)
- **先最大化再全屏时桌宠没有躲开(Windows)**:从最大化状态按 F11 进全屏,以前不算全屏。现在按窗口有没有标题栏判断,带标题栏的最大化窗口(包括设为置顶的)不算全屏。手动显示过桌宠之后,「全屏时自动隐藏」照常生效。(#89)
- **对话页重启后,旧的提问还显示成可以回答**:现在只有 Coo 还在等回答的提问能点。(#81)
- **对话页翻到较早的对话时,撤回过的消息又出现**;排过队的消息在较早一页里放回 Coo 看到它的位置。(#80)
- **重启前排队、重启后补投的消息**,送达后也会挪到 Coo 看到它的位置。(#81)

## 已知问题

- **macOS 上用大肥鱼时开一段时间会卡**:卡的时候桌宠的绘制占满了 GPU。原因还在排查,需要在 Mac 上实测,修复会放在后续版本。卡得影响使用时可以先换成 Coo。(#86)

## 下载

- Windows x64:`Coopanion-Setup-0.1.18.exe`
- Apple 芯片 Mac:`Coopanion-0.1.18-mac-arm64.dmg` / `.zip`
- Intel Mac:`Coopanion-0.1.18-mac-x64.dmg` / `.zip`
- Linux x64:`Coopanion-0.1.18-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`:七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`:自动更新读的版本信息,不用下载。

Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证,第一次打开的方法见 README。
