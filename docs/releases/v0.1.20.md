# Coopanion v0.1.20

**11 种界面语言,新增 OpenAI、Anthropic、Gemini、xAI,法德西葡意俄语可以语音输入,装扮页能导入形象包**

## 新功能

- **11 种语言**:简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、Español (Latinoamérica)、Português (Brasil)、Italiano、Русский。新装跟随系统语言,系统语言不在其中时用英文;升级上来的保留原来的语言。在「习惯」页第一行「语言」里切换,托盘、桌宠、设置窗口立刻换,不用重启。
- **Coo 说你的语言**:应用语言是简体或繁体中文时 Coo 读中文的人设和提示词,其他语言读英文版;简体中文和英文以外的语言,还会告诉 Coo 用应用语言和你说话。没改过的初始人设会随语言换成另一版,从下一个 session 起生效;改过的不动。
- **更多模型服务**:新增 OpenAI、Anthropic、Gemini、xAI。Kimi、通义千问、MiniMax、智谱 GLM 加上国际平台,应用语言是简体中文时默认国内平台,其他语言默认国际平台,「开始」页可以切换。服务的排序跟着语言走,简体中文以外豆包、百度千帆、阶跃星辰收在「更多」里。
- **法、德、西、葡、意、俄语的语音输入**:这几种语言改用 Whisper(small 模型,约 360 MB)在本机识别,一句说完后出字;中、英、日、韩文仍用 FunASR。
- **导入形象包**:装扮页形象一栏末尾的「导入」可以从 zip 或文件夹安装形象包,也可以直接拖到页面上。按形象 API 2 写的包在之后的版本里照常加载。
- **引导**:新增「你是从哪里认识我的?」;没接通模型时跟 Coo 说话,它会先问要不要去接通。
- **电脑操作默认问一次**:新装默认首次动鼠标键盘前问一次,同意后 30 分钟内不再问;已有安装保留原来的每轮都问。

## 修复

- **阶跃星辰、通义千问开思考时报解析错误**:它们的流式推理事件现在先转成标准事件再校验。
- **通义千问、阶跃星辰、百度千帆、智谱国内平台操作电脑时可能报 400**:这几家的工具结果只收文字,截图改放在紧跟的一条消息里。
- **百度千帆不能看图**:改走 Chat Completions,默认模型换成能看图的 `glm-5.3-flash`。
- **智谱 GLM-5.3 系列选「不思考」时报错**:这个系列不能关思考,改发最低一档。
- **换形象后 Coo 不知道词表变了**:换形象时会告诉 Coo 哪些表情动作不能用了、哪些是新的。

## 下载

- Windows x64:`Coopanion-Setup-0.1.20.exe`
- Apple 芯片 Mac:`Coopanion-0.1.20-mac-arm64.dmg` / `.zip`
- Intel Mac:`Coopanion-0.1.20-mac-x64.dmg` / `.zip`
- Linux x64:`Coopanion-0.1.20-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`:七个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`:自动更新读的版本信息,不用下载。

Windows 版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证,第一次打开的方法见 README。除简体中文和英文外的译文由模型翻译,欢迎提 PR 修正。
