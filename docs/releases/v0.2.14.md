# Coopanion v0.2.14

**连发消息不再只出第一条回复;自动更新可以关闭;安装没装完时会提示重新安装**

## 新功能

- **自动更新开关**:「习惯 → 通用 → 自动更新」默认开启。关闭后停止检查、取消正在进行的下载，已下载的更新也不再安装(感谢 @leafliber,#475)。
- **左右声道开关**:「习惯 → 音效」新增「按位置分配左右声道」,默认开启;关闭后音效和说话声都居中播放(#494)。
- **大肥鱼的眼睛高光会动**:原版配色的大肥鱼，眼睛高光跟着视线和眨眼动，难过、害羞时放大颤动，生气、认真时缩小，半闭眼时也还在。其他配色暂时不变(#258)。
- **形象包可以读自己目录里的文件**:形象包的页面可以用 `fetch` 读取包内的文件，比如 Live2D 模型和贴图;读不到其他包和 Coopanion 自己的接口。写法见形象包 README 的「读包里的文件」(#469)。

## 修复

- **连发消息只出第一条回复**:鼠标在 Coo 的气泡上停过以后，桌宠有时以为鼠标一直没离开，这句话一直不收，后面排队的回复和提问也出不来。现在按真实的光标位置判断。
- **Coo 贴着屏幕边时声音只剩一边**:按位置分配声道时，远侧声道最低只压到约 -8 dB,戴耳机不再像单声道(#493)。
- **工作区堆满文件时 Coo 反复交接**:Coo 的工作区里有上万个文件的目录(比如 Python 虚拟环境)时，上下文怎么交接都降不下来，Coo 会一直交接、提醒、再交接。现在很深的目录在清单里折成一行;交接后仍然降不下来时停止交接，照常运行，并请 Coo 找时间整理记忆(#496)。
- **安装没装完**:安装或更新中途被打断、程序文件缺失时，不再反复重启 Core,改为提示从下载页重新安装到原来的文件夹，设置、API Key、提示词和记忆都会保留;安装包装完后的检查也会检查这个文件(#479)。
- **macOS 上右侧修饰键**:说话键设成右侧 Option、Control、Command 时可以触发(感谢 @ink1453 在 Mac 上验证,#458)。
- **从源码运行时任务栏图标**:开发版和已安装的 Coopanion 不再共用同一个任务栏身份，开发版不会把已安装版的任务栏图标换掉。

## 改动

- **cortico 子模块升到 v0.2.10**:运行中某个 World 出错时只停掉这一个，其余 World 和 Coo 照常运行，「World 总览」里显示原因,Coo 也会收到一句说明(感谢 @leafliber);配置接口收到配置组里没有声明的键时整体拒绝，并提示可能想写的键，以前会静默丢掉、照样回报已写入(#491)。

- Apple 芯片 Mac:`Coopanion-0.2.14-mac-arm64.dmg` / `.zip`

Windows 安装版和 AppImage 会自动更新到这个版本。macOS 版本仍是临时签名、未经 Apple 公证，第一次打开的方法见 README。除简体中文和英文外的译文由模型翻译，欢迎提 PR 修正。
